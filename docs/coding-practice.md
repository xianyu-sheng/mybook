# Mybook 刷题计划

「刷题计划」是全局工作区，不依赖某一本笔记本。创建策略时填写企业、部门、岗位、JD 和标签，Mybook 会保存这些信息，之后可以从侧边栏继续上次进度。

每套策略都有自己的题目顺序、状态、作答、AI 复盘和同步记录。同一题的公共题面元数据只保存一份，所以“字节后端”和“快手后端”可以复用题目，但互不影响掌握状态和答案。

题源搜索使用公开搜索摘要，并限制在牛客、小红书、CodeTop、力扣和灵神题单等允许域名。摘要会保存 URL、检索时间和“未经来源确认”的提示；它是检索线索，不代表企业必考题。网络搜索不可用时，内置公开题单仍可以生成基础到进阶的顺序。

作答先写入本地数据库，再调用当前可用的模型进行静态点评。点评包括思路、代码、正确性、时间/空间复杂度、边界、替代方案、进阶追问和薄弱知识点。Mybook 不在 Electron 主进程执行用户代码，也不把 AI 参考实现当作在线评测结果。模型超时或返回不完整内容时，原答案保留在历史记录中，可以重新点评。

力扣同步读取已连接账号的近期提交快照；牛客当前读取公开统计快照。同步只写入外部记录和匹配关系，不覆盖本地答案、复杂度填写或 AI 复盘。平台接口变化、登录过期和完整历史题目导入需要在页面提示后处理。

推荐流程：先粘贴 JD，生成顺序；再搜索公开题源并核验链接；按顺序独立作答；把“已掌握”留给能够解释边界和复杂度的题目；隔一段时间回到历史复盘重做。真正掌握以自己的推导和实际运行结果为准。
